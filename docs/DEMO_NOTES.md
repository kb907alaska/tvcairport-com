# TVC Interactive MVP Prototype Demo Notes

**Live Demo URL**: [https://tvcairport-com.pages.dev/](https://tvcairport-com.pages.dev/)  
**Prepared For**: Northwest Regional Airport Authority (NRAA) Evaluators  

---

## Key Evaluator Walkthrough Flow

1. **Homepage Passenger Dashboard (`/`)**:
   - Live arrivals and departures flight toggle bar with quick code search.
   - Emergency Travel Advisory alert banner.
   - Quick task action grid: Catch a Flight, Pick Someone Up, Park at TVC, Ground Transportation.
   - Interactive passenger journey timeline: Arrive -> Check In -> Security -> Terminal -> Fly.
   - Gates to the Future terminal expansion project showcase.

2. **Flights Module (`/flights`)**:
   - Dynamic arrivals/departures status table.
   - Airline filter (Delta, American, United, Allegiant, Sun Country).
   - Nonstop routes directory (`/flights/nonstop-destinations`).

3. **Parking & Transportation Hub (`/parking-transportation`)**:
   - Interactive parking cost estimator tool.
   - SVG Terminal parking map.
   - Ground transportation & rental car options.

4. **NRAA Governance & Public Documents (`/documents` & `/nraa/meetings`)**:
   - Searchable document repository with category and year filters.
   - Downloadable Board meeting agendas, packets, and minutes.
   - Secured Board Portal vault prototype (`/board-portal`).

5. **Agency Strategy & Proposal (`/proposal`)**:
   - Complete technical breakdown of FOURAK's proposal response for RFP 2026-01.
